# PichaiFX Autotrad — เว็บไซต์ Next.js

หน้าเว็บ landing page สไตล์ Trading Technology Platform ตามคอนเซปต์ที่ออกแบบไว้
(Dark background, Neon Cyan/Electric Blue, Dashboard/Terminal look)

## เทคโนโลยีที่ใช้

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS (กำหนด design token สีและฟอนต์ไว้ใน `tailwind.config.ts`)
- ฟอนต์: Inter (เนื้อหา), Space Grotesk (หัวข้อ), IBM Plex Mono (ตัวเลข/ข้อมูล) โหลดผ่าน `next/font/google`

## วิธีติดตั้งและรัน

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18.18 ขึ้นไป

```bash
# ติดตั้ง dependencies
npm install

# รันโหมดพัฒนา (dev server)
npm run dev
```

จากนั้นเปิด http://localhost:3000

> หมายเหตุ: ตอนรัน `npm run build` หรือ `npm run dev` ครั้งแรก เครื่องต้องต่ออินเทอร์เน็ต
> เพื่อดาวน์โหลดฟอนต์จาก Google Fonts (เกิดขึ้นอัตโนมัติผ่าน `next/font`)

## Build สำหรับ production

```bash
npm run build
npm run start
```

## ฟีเจอร์ที่เพิ่มเข้ามา

- **พื้นหลังกราฟแท่งเทียนเคลื่อนที่** (`components/CandlestickBackground.tsx`) — แถบกราฟแท่งเทียนวิ่งต่อเนื่องแบบวนลูปที่ขอบล่างของหน้าจอ อยู่ด้านหลังเนื้อหาทั้งหมด (`position: fixed`, ตำแหน่งข้อมูลถูกสุ่มแบบ deterministic ไม่เปลี่ยนทุกครั้งที่โหลดหน้า จึงไม่มีปัญหา hydration) หยุดเคลื่อนไหวอัตโนมัติถ้าเบราว์เซอร์ตั้งค่า "ลดการเคลื่อนไหว" (`prefers-reduced-motion`)
- **สลับโหมดกลางวัน/กลางคืน** — ปุ่มรูปพระอาทิตย์/พระจันทร์ในเมนู (`components/ThemeToggle.tsx`) สลับ `data-theme` บน `<html>` ระหว่าง dark (ค่าเริ่มต้น) กับ light จำค่าไว้ใน `localStorage` และมีสคริปต์เล็ก ๆ ใน `app/layout.tsx` ทำงานก่อน React hydrate เพื่อไม่ให้จอกะพริบผิดสี สีทั้งหมดของเว็บ (ink, panel, cyan, mint, rose ฯลฯ) ถูกกำหนดเป็น CSS variable ใน `app/globals.css` ภายใต้ `:root` (กลางคืน) และ `[data-theme="light"]` (กลางวัน) จุดเดียว จึงสลับได้ทั้งเว็บพร้อมกัน
- **กล่องข้อความแจ้งบัญชีเทรดถึงแอดมิน** (`components/ConnectAccount.tsx`, ส่วน "แจ้งบัญชีเทรดให้แอดมิน") — ฟอร์มให้สมาชิกกรอกชื่อ ช่องทางติดต่อกลับ โบรกเกอร์ เลขบัญชี เซิร์ฟเวอร์ และข้อความเพิ่มเติม เพื่อแจ้งแอดมินว่าต้องการใช้บัญชีใดกับระบบเทรดอัตโนมัติ (ไม่มีการขอรหัสผ่านใด ๆ ในฟอร์มนี้ — แอดมินจะติดต่อกลับเพื่อแจ้งขั้นตอนต่อไปเอง)

  > **สำคัญ — ต้องทำเพิ่มก่อนใช้งานจริง:** ตอนนี้ฟอร์มนี้เป็นเพียง UI ฝั่ง frontend (เก็บ state ไว้ในเบราว์เซอร์ชั่วคราวเท่านั้น ยังไม่ได้ส่งข้อมูลไปที่ไหน) ต้องต่อกับ backend หรือบริการอย่าง Google Forms / Airtable / LINE Notify / อีเมล เพื่อให้ข้อมูลที่สมาชิกกรอกจริง ๆ ถูกส่งไปหาแอดมิน

## ระบบสมาชิก + ค่าแนะนำ 3 ชั้น

สมาชิกสมัคร/ล็อกอินได้ที่ `/register` `/login` แล้วดูรายได้ที่ `/dashboard` ส่วนแอดมินจัดการที่ `/admin`

**กติกาค่าแนะนำ** (แก้ได้ที่ `lib/commission.ts` ไฟล์เดียว) — ราคา EA 1,990 บาท = 100%
ตัด 40% (796 บาท) จ่ายสามชั้น มากไปน้อย:

| ชั้น | ผู้รับ | % ของ 1,990 | บาท |
|---|---|---|---|
| 1 | ผู้แนะนำโดยตรง | 20% | 398.00 |
| 2 | ผู้แนะนำของชั้น 1 | 12% | 238.80 |
| 3 | ผู้แนะนำของชั้น 2 | 8% | 159.20 |

**ขั้นตอนการทำงาน**
1. สมาชิกแชร์ลิงก์ `/register?ref=รหัสของตัวเอง` — ผู้สมัครใหม่จะถูกผูกกับผู้แนะนำถาวร
2. ผู้สมัครล็อกอินแล้วกรอกฟอร์ม "แจ้งบัญชีเทรด" บนหน้าแรก (ต้องล็อกอินก่อน) -> เข้า `/admin` สถานะ "รอดำเนินการ"
3. แอดมินตรวจว่าได้รับเงิน 1,990 บาทแล้วกด "อนุมัติ" -> ระบบสร้างค่าแนะนำให้สายบน 3 ชั้นอัตโนมัติ (ถ้าสายสั้นกว่า 3 ชั้น ส่วนที่ไม่มีคนรับไม่ถูกจ่ายใคร)
4. แอดมินโอนเงินแล้วกด "ทำเครื่องหมายจ่ายแล้ว" -> สมาชิกเห็นสถานะ "จ่ายแล้ว" ในแดชบอร์ด

**ตั้งค่า (.env.local)** — ดู `.env.example`
- `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` (ใช้ตัวเดียวกับตัวนับผู้เข้าชม — ข้อมูลสมาชิกเก็บที่นี่)
- `SESSION_SECRET` สตริงสุ่มยาว ๆ (`openssl rand -base64 32`)
- `ADMIN_EMAILS` อีเมลแอดมิน สมัครสมาชิกด้วยอีเมลนี้ก่อน แล้วจะเห็นปุ่ม "จัดการระบบ"

**ความปลอดภัยที่ใส่ไว้แล้ว**: รหัสผ่านแฮชด้วย scrypt, คุกกี้ล็อกอิน httpOnly ลงลายเซ็น HMAC, จำกัดลองรหัสผ่าน 8 ครั้ง/15 นาที,
บัญชีเทรดหนึ่งบัญชีแจ้งได้ครั้งเดียว (กันรับค่าแนะนำซ้ำ), อนุมัติซ้ำไม่ได้ (lock), ชื่อลูกข่ายในแดชบอร์ดถูกซ่อน (`สม***`)

> **ก่อนเปิดใช้งานจริง:** ควรอัปเดตนโยบายความเป็นส่วนตัว/ข้อตกลงให้ครอบคลุมการเก็บข้อมูลสมาชิกและโปรแกรมค่าแนะนำ
> และปรึกษานักกฎหมายเรื่องกฎหมายขายตรงฯ / การห้ามแชร์ลูกโซ่ (ค่าแนะนำต้องมาจากการขายสินค้า/บริการจริง ไม่ใช่การหาสมาชิก)

  Navbar.tsx        # เมนูบนสุด (responsive, sticky)

  TrustBar.tsx      # แถบจุดเด่นสั้น ๆ
  Performance.tsx   # ผลการเทรด/ตัวเลขจริง + กราฟ equity curve
  Products.tsx      # การ์ดสินค้า (EA, Copy Trading, AI Analytics, Tools)
  HowItWorks.tsx    # ขั้นตอนการใช้งาน 4 ขั้นตอน
  CopyTrading.tsx   # รายการกลยุทธ์ Copy Trading
  LiveMarket.tsx    # แถบราคาตลาดวิ่ง (ticker)

  Academy.tsx       # บทความให้ความรู้
  Faq.tsx              # คำถามที่พบบ่อย (accordion, client component)
  ConnectAccount.tsx   # กล่องข้อความแจ้งบัญชีเทรดถึงแอดมิน
  CandlestickBackground.tsx  # พื้นหลังกราฟแท่งเทียนเคลื่อนที่

  Footer.tsx           # ท้ายเว็บไซต์

## ปรับแต่งสี/ฟอนต์

แก้ไขได้ที่ `tailwind.config.ts` ในส่วน `theme.extend.colors` และ `fontFamily`
ทุก component เรียกใช้สีผ่านชื่อ token เช่น `bg-ink`, `text-cyan`, `border-line`
เพื่อให้เปลี่ยนธีมทั้งเว็บได้จากจุดเดียว

## เนื้อหาที่ควรแทนที่ด้วยข้อมูลจริงก่อนเผยแพร่

- ตัวเลขผลการเทรดใน `Performance.tsx` และ `CopyTrading.tsx` (ปัจจุบันเป็นข้อมูลตัวอย่าง)
- ลิงก์ Myfxbook จริงใน `Performance.tsx`
- ช่องทางติดต่อใน `Contact.tsx` (LINE / Telegram / อีเมล)

- **ข้อมูลนิติบุคคลและช่องทางติดต่อในหน้ากฎหมาย** (`app/privacy-policy/page.tsx`,
  `app/terms/page.tsx`, `app/risk-warning/page.tsx`) — ดูหัวข้อถัดไป

## PDPA / นโยบายความเป็นส่วนตัว

เพิ่มระบบที่เกี่ยวข้องกับพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) ดังนี้

- **หน้านโยบายความเป็นส่วนตัว** — `app/privacy-policy/page.tsx` (เส้นทาง `/privacy-policy`)
  ครอบคลุมข้อมูลที่เก็บ วัตถุประสงค์ ฐานทางกฎหมาย คุกกี้ การเปิดเผยข้อมูลต่อบุคคลที่สาม
  การโอนข้อมูลไปต่างประเทศ ระยะเวลาเก็บรักษา มาตรการความปลอดภัย และสิทธิของเจ้าของข้อมูล
- **หน้าข้อตกลงการใช้งาน** — `/terms` และ **หน้าคำเตือนความเสี่ยง** — `/risk-warning`
  (ใช้ shell เดียวกันจาก `components/LegalPageShell.tsx`)
- **แบนเนอร์คุกกี้ (Cookie Consent)** — `components/CookieConsent.tsx` แสดงเมื่อผู้ใช้เข้าเว็บครั้งแรก
  ให้เลือก "ยอมรับทั้งหมด", "ปฏิเสธที่ไม่จำเป็น" หรือ "ตั้งค่า" (เปิด/ปิดคุกกี้วิเคราะห์การใช้งาน
  แยกจากคุกกี้ที่จำเป็น) บันทึกการเลือกไว้ใน `localStorage` และเปิดขึ้นมาใหม่ได้ทุกเมื่อผ่านลิงก์
  "ตั้งค่าคุกกี้" ที่ท้ายเว็บไซต์ (Footer)
- **Checkbox ยินยอม PDPA ในฟอร์ม** — `components/ConnectAccount.tsx` เพิ่ม checkbox บังคับ
  ให้ผู้ใช้ยืนยันว่าอ่านและยินยอมตามนโยบายความเป็นส่วนตัวก่อนกดส่งข้อมูลทุกครั้ง

> **สำคัญ:** เนื้อหาในหน้ากฎหมายทั้งสามหน้าเป็น **แม่แบบทั่วไป** เท่านั้น ไม่ถือเป็นคำแนะนำ
> ทางกฎหมาย ก่อนเผยแพร่ใช้งานจริง ต้อง:
> 1. แก้ไขชื่อนิติบุคคล ที่อยู่ และช่องทางติดต่อ (อีเมล/LINE) ให้เป็นข้อมูลจริงของธุรกิจคุณ
>    ในไฟล์ `app/privacy-policy/page.tsx`
> 2. ให้ที่ปรึกษากฎหมายหรือผู้เชี่ยวชาญด้าน PDPA ตรวจสอบเนื้อหาให้ตรงกับลักษณะการเก็บ/ใช้ข้อมูล
>    จริงของธุรกิจคุณ (เช่น ถ้าต่อ CRM, ระบบชำระเงิน หรือเก็บข้อมูลเพิ่มเติมในอนาคต ต้องปรับปรุงนโยบาย)
> 3. หากธุรกิจของคุณเข้าเกณฑ์ต้องแต่งตั้งเจ้าหน้าที่คุ้มครองข้อมูลส่วนบุคคล (DPO) ตาม PDPA
>    ให้ระบุชื่อ/ช่องทางติดต่อ DPO ในหน้านโยบายด้วย
